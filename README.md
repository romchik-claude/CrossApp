# CrossApp

Наскрізний проєкт з крос-платформного програмування.

Предметна область: Замовлення.
Сутності: Customer (клієнт), Product (товар), Order (замовлення), OrderLine (рядок замовлення).
Призначення: оформлення замовлень і підрахунок сум.

## Запуск

dotnet build
dotnet run --project src/Cli

## Середовище

.NET SDK 10.0.401, Windows 10 x64

## Публікація self-contained

| linux-x64 | 78.79 МБ       |

Linux-x64 більший на ~2 МБ через відмінності у системних бібліотеках.

я захичаю лабораторну

## Режими публікації

| RID     | Режим               | Розмір publish | Потрібен runtime |
| ------- | ------------------- | -------------- | ---------------- |
| win-x64 | self-contained      | 76.85 МБ       | ні               |
| win-x64 | framework-dependent | 0.19 МБ        | так (.NET 10)    |

Різниця: self-contained містить весь .NET runtime всередину, тому набагато більший (76+ МБ) але запускається без встановленого .NET. Framework-dependent містить лише додаток (0.2 МБ) і потребує встановленого .NET на цільовій машині.

Коли використовувати:

- Self-contained: кінцевий користувач, який не має .NET встановлено
- Framework-dependent: сервер або машина розробника з установленим .NET
